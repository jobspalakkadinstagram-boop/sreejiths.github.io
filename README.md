# Sreejith S — Portfolio Website

A classy, modern, responsive one-page portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — visual design and responsive layout
- `script.js` — scroll progress and reveal animation

## Use it online
1. Open the folder in VS Code or any text editor.
2. Replace the `SS` placeholder in the hero with your professional photo if desired.
3. Edit any text in `index.html`.
4. Upload the three files to a static hosting service such as GitHub Pages, Netlify or Vercel.
5. Your portfolio can then be opened through the hosting URL.

The portfolio content was populated from the CV PDF supplied in this conversation. Review phone number, dates, qualification wording and certification spelling before publishing.
